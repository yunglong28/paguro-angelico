04
Rules
What the board has in common, and how Time Bank Spirit takes it.

    

      
The eyes are the logo
Two glossy eyes, one hard highlight each, set wide. They must read at 32 px. Mouths stay small. Chao · Toro · Pipo-kun

      
Primitives, sculpted
Spheres, capsules and rounded boxes blended as one SDF surface. Never stacked balls, never painted detail. Bomberman 64 · Hokkun

      
One light, one highlight
A key light, a hard specular dot and a soft contact shadow, with no outlines. It is a pre-rendered object, not an illustration. N64 box art · Lightscape

      
Five inks only
Toner, blu, fluo, rosso and paper. Print screens them, 3D paints them, Y2K turns them into chrome, candy and gel. Don't add new colours.

      
Silhouette first
Claws, shell and apparatus must read filled solid black. If the shape needs its colour to be legible, it isn't finished.

      
No text on the image
No captions, crop marks or logos inside the render. Names live outside the plate, as they do on this page.

      
The crab is the host
The hermit crab lives in a borrowed house. The apparatus (wings, halos, towers, chains) makes each one a character.

      
One model, every look
The print, the 3D and the Y2K box art are the same object with the same proportions. Never redraw it for one medium.
